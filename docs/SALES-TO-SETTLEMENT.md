# 从一张销售交单到两台签收核账

[公开销售交单](https://cscpengyuyan.github.io/haha-logistics-dispatch/v12/#sales) · [续办达拉斯两台演练](https://cscpengyuyan.github.io/haha-logistics-dispatch/v12/#rehearsal) · [海运计划](https://cscpengyuyan.github.io/haha-logistics-dispatch/v12/#ocean)

公开版默认以演练管理员进入。以下步骤使用虚构订单 DEMO-DAL-02。请在同一浏览器内续办。使用手册提供演练重置。

1. **销售、物流**。在销售交单页下载达拉斯两台示例 XLSX，上传刚下载的文件，核预检后确认导入。点「澄清终点并接手」，按演练合同选 L3 并勾选 SIM-MAIN-ST-DOCK 现场核验。该单未买技术启用。
2. **仓管、采购**。打开「达拉斯两台演练」，核对并锁定列出的两个 SN。进本票采购页，从零生成询价包，录入四份虚构回价。A 的 $240 只到路边，B 的 $510 与 C1 的 $545 覆盖机位，C2 的 $490 尚缺二程承接。选 B 为主、C1 为备，填写批准号、选择原因及切换条件，登记书面委托号。
3. **调度、仓管、车组、财务**。回「达拉斯两台演练」，进入本票地图，计算并保存道路试排。回演练页按本票资料签发。在「预约与短信」填入虚构资料、保存预约，选 T2 排入预发并模拟到时送达。回演练页办仓口移交，勾选两个 SN、提交签收，核对 $510 并结账。每步可从本票时间线查回执。

企业共享服务上的不同岗位使用各自账号。公开版数据按浏览器隔离。演练入口的书面凭据、授权、POD 和发票均为合成资料。公开 Dallas 路线在本机浏览器计算，签发、实物交接仅在演练库发生。

## 验收口径

- 录入原件、例表和系统模板分别留证。系统生成的下载工作簿已做下载、上传、改版和去重测试。交付本版时未获得用户的《销售交单收集表.xlsx》原件，请用原件再验列名、枚举、单元格格式及业务行。
- 美国多点道路采样、运行日期、引擎、里程和覆盖差额见 [州与 DC 逐项结果](verification/road-coverage.csv) 与 [货车路网部署](TRUCK-ROUTING.md)。全国视野可操作，仅 Dallas 市区有本次可复现的货车求解。第三方瓦片可用性依赖图源。
- 正式短信需运营方配置发送身份、服务端密钥、HTTPS 回调及持久化 worker，并由有许可的收件人完成付费实证。账户收费以运营合同为准。[短信运行说明](SMS-OPERATIONS.md)
- 员工端在本地持久化 SQLite 服务做多角色会话验收。公司公网域名、持续在线主机、员工账户和真实终端需运营方提供。[员工部署、备份与还原](V12-DEPLOY.md)
- 同一明细有多台设备但购买了不同服务时，在销售表拆成不同明细行，分别留购服依据。库存逐台核验和签收可追溯到 SN。
