## 一、本次改了什么

### 1. 全局 UI 设计系统（新增 `theme.css`）
在原有各模块样式之后加载，重写设计令牌与公共组件，**所有页面同时生效**：

| 项目 | 变化 |
| --- | --- |
| 色彩 | 更深的松绿导航（`#0d2f2a→#0b2b26`），主色统一为 `#0f6a58`，荧光绿仅用于选中态与"今天"标记 |
| 画布 | 浅米绿底色 + 极淡径向光晕，卡片纯白、1px 描边 + 双层阴影，圆角 18px |
| 字体 | 标题字重 660、字距收紧（-0.02~-0.045em），数字统一等宽数字（tabular-nums） |
| 导航 | 分组标题带渐隐分隔线，选中项为荧光绿胶囊 + 深绿文字，图标常态 62% 透明、选中 100% |
| 顶栏 | 52–60px 粘性半透明毛玻璃，面包屑 + 版本徽标 + 环境徽标（演练态为琥珀色） |
| 按钮 | 三层层次：主操作渐变绿、次操作白底描边、文字按钮；统一 9–10px 圆角与焦点环 |
| 表单 | 统一 36px 高、10px 圆角、自绘下拉箭头、聚焦绿色描边环；文件选择器改为虚线投放区 |
| 表格 | 表头小字大写 + 字距，行分隔线更淡，悬停整行染色，数字右对齐等宽 |
| 弹窗 | 20px 圆角 + 模糊遮罩 + 分层阴影 |
| 响应式 | ≤1280 / ≤1020 / ≤760 三档断点重排；移动端抽屉导航、标题与操作按钮换行、统计卡两列 |

同时修掉两个原有视觉缺陷：
- 待办页两条跳转链接直接 `prepend` 到内容区，渲染成行内下划线文字并与统计卡重叠 → 改为 `.quick-links` 胶囊按钮行；
- 按钮全局样式只作用于绘制层（颜色/圆角/字体），不再覆盖 `display/gap/white-space`，避免地图订单池等复合按钮被压成一行截断。

### 2. 海运计划看板（重写 `ocean-desk.js` + 新增 `ocean-board.css`）

原实现：一张 5 列表格 + 两行 4px 内联色条，没有刻度、没有汇总、没有对比。

新实现：**以甘特图为主体的看板**

```
┌ 筛选（全部/待收/超期/有改约）· 目的仓 · 搜索 · 导出 ────────────────┐
├ KPI：航次 / 待收台数 / 超期未收 / 改约待办 ───────────────────────┤
├ 到仓甘特（周/日刻度切换）                        │ 到仓周负荷        │
│  SIM-SHA-HOU-02  ═══════ 航次汇总条  [超期7天]   │ 排期健康度        │
│    订舱与截关   ◆截单 ◆截关                      │ 改约待办          │
│    海上运输     ███████ 24 天                    │                   │
│    内陆派送           ▨ 1 天                     │                   │
│    到仓确认        ○╌╌● 冻结 vs 预测            │                   │
├──────────────────────────────────────────────────┴───────────────────┤
```

关键点：
- **按航次分组**，每组 4 条泳道：订舱与截关（里程碑菱形）、海上运输、内陆派送（斜纹段）、到仓确认；
- **冻结 vs 预测**：冻结到仓为空心圈，预测到仓为实心绿圈，两者不一致时用琥珀虚线连出偏差，左侧写明 `冻结 10/23 · 预测 10/25 · +48h`；
- **时间轴**：周刻度（MM/DD）与日刻度（每 4 天标注）两档，网格线对齐表头，荧光绿竖线为"今日"；
- **窗口自适应**：自动纳入截单/截关等最早节点；有超期批次时把时间窗延伸到今天，让"超期"在图上可见；
- **航次汇总条**：整段 截单→到仓 的浅色条，右端紧跟状态胶囊（超期 7 天 / 距到仓 3 天 / 已收清）；
- **右侧三块**：到仓周负荷（周一起算，含"同周多批到仓"提醒）、排期健康度（准点/延后/平均偏移）、改约待办（可点开对应航次）；
- **交互**：状态筛选（带计数）、目的仓下拉、关键字搜索（保持光标位置）、周/日刻度切换、点击航次整块跳转到下方单票跟踪、导出 CSV（新增柜号、装船、到港、延迟小时、已收台数、改约原因）；
- **空状态**：区分"无数据"与"筛选无结果"，后者给一键清空筛选；
- 保留原有 `Supply.sea` 单票船期跟踪与 `Resources` 历史交接，并对齐新配色（原计划灰 / 最新预计绿 / 实际回执蓝）。

### 3. 其他页面收益（无需改模块代码）
仪表盘、订单工作台、逐台库存、运输采购、经营复盘、地图调度、费用核对、仓口验放、预约短信等页面，全部通过 `theme.css` 获得新的卡片、表格、按钮、徽标与响应式表现；地图页订单池、复盘页指标块等模块自定义样式做了兼容性修补。

## 二、如何部署

1. 把 `v13/` 整个目录放到 `haha-logistics-dispatch` 仓库根目录（与 `v12/` 同级）；
2. 提交并推到 `main`，GitHub Pages 会自动发布；
3. 访问 `https://cscpengyuyan.github.io/haha-logistics-dispatch/v13/#ocean`。

本地预览（需带 `v12` 的离线运行库，目录已含）：
```powershell
cd <仓库根目录>
python -m http.server 8901
# 浏览器打开 http://127.0.0.1:8901/v13/#ocean
```

> 首次打开仍需加载 Pyodide 运行库与地图瓦片，约 10–30 秒；数据全部为虚构演练数据。
